# 智能物流调度与路径规划系统 (Logistic Planner)

企业级多车型路径规划、门店分组排班与物流基础设施配置的可视化决策平台。前后端分离架构，基于 **高德地图 JS API 2.0** 与 **运筹优化求解器**，提供高精度路网测算、全自动排班调度与轻量化数据持久化支持。

---

## 🌟 核心功能矩阵

### 1. 基础配置与主数据管理
- **门店维护 (`/config/store`)**：
  - 支持按仓库编码（`dc_code`）、所属店群、行政区划、本埠/外埠等多维度快速筛选与检索；
  - 提供标准 **Excel (`.xlsx`) / CSV 导入模板下载**，内置字段规范与示例数据；
  - 智能表头映射引擎：自动识别中英文及常见业务别名，支持覆盖导入与追加导入预览；
  - 门店数据导出（严格导出 `dc_code`、所属店群、经纬度、频次、箱数、车型限制及卸货耗时等属性）；
  - 支持单门店新增、编辑与实时修改。
- **车型运力维护 (`/config/vehicle`)**：
  - 维护系统车型库，包括车型编码、车型名称、最大载重（箱）、货箱容积（m³）、每公里运输成本、可用车辆数与激活状态；
  - 路线规划时可直接从车型库中选用并分配运力。
- **起点 / 中心仓管理 (`/config/depot`)**：
  - 维护各物流中心/起点仓库编码（`dc_code`）、仓库名称、经纬度坐标与吞吐能力；
  - **经纬度智能逆地理编码**：输入或变更经纬度后，系统自动调用高德 API 识别并回填详细物理门牌地址；
  - 支持设置默认中心仓。

---

### 2. 门店分组与周排班规划
- **新建门店规划 (`/clustering/create`)**：
  - 3 步向导式创建流程：选择中心仓 ➔ 筛选作业门店 ➔ 配置分组策略；
  - 提供三种策略：
    - **智能约束分组求解**（带容量与距离约束）；
    - **行政区划归属分组**（纯行政区划聚合）；
    - **行政区扩展拆分分组**（行政区合并与跨区拆分）。
- **门店分组 (`/clustering/plan`)**：
  - 地图可视化呈现各店群聚类边界与几何中心点；
  - 支持直接在地图上拖拽/切换门店所属店群，并实时重算店群负载与距离指标。
- **门店排班 (`/clustering/schedule`)**：
  - 支持 1~7 次/周配送频次约束下的全周配送作业日（周一至周日）智能均衡排程；
  - 平滑各作业日总装载箱数与配送门店数，避免运力峰谷波动。
- **店群历史结果 (`/clustering/history`)**：
  - 完整记录历史方案，清晰区分 **💾 用户手动保存** 与 **⚡ 算法自动运行** 记录；
  - **📥 方案结果数据下载**：支持一键导出 **门店分组明细（含所属店群与指标汇总）**、**门店排班结果（含作业日分配与每日运力汇总）** 以及 **路线规划明细** 为标准 Excel (`.xlsx`) 表格；
  - 支持一键将历史方案重新载入工作台。

---

### 3. 多车型路线规划与调度
- **智能运筹求解 (`/routing/plan`)**：
  - 基于容量约束车辆路径问题（CVRP）求解引擎，支持单日规划与全周多作业日全局排程；
  - 严格满足各车型装载率上限（`max_capacity_rate`）、求解耗时上限（`time_limit_seconds`）与闭环回仓策略（`return_to_depot`）。
- **全景可视化与灵活调线**：
  - 支持「全部时间 (全周总览)」与「周一至周日」单日视图平滑切换；
  - 展开查看每条路线的到店次序、单店运量与行驶轨迹；
  - 支持在门店浮窗中一键将门店**转移到其他路线**或**新建独立路线**。
- **🗺️ 高德真实路网货车测算与高精轨迹**：
  - **单路线测算**：路线明细中提供「🗺️ 高德路线」功能，调用 `AMap.TruckDriving`（智能双模降级至 `AMap.Driving`），精准测算真实货车道路里程（km）、预估行驶耗时与高速过路费；
  - **真实弯道轨迹渲染**：测算成功后地图折线自动升级为贴合真实道路、高架桥与匝道的高精路网轨迹；
  - **⚡ 一键批量路网测算**：支持对当前所有路线全自动串行测算，内置 **0.6s 平滑休眠流控**，防止高并发触发高德 QPS 配额限制；
  - **方案持久化**：支持将路线结果保存至历史方案库，并可随时回载与二次调线。

---

### 4. 画布工作台与自由编辑 (Canvas Workspace)
- **自定义配送区域与路线绘制 (`/canvas/workspace`)**：
  - 提供高自由度的地图交互画布，支持用户自由绘制配送区域多边形（Polygon）和自定义路线；
  - 动态图层管理，支持多图层叠加、隐藏与样式动态切换，直观呈现不同规划方案的效果对比。
- **状态快照与历史版本控制**：
  - 内置了撤销（Undo）与重做（Redo）及快照版本控制机制，确保复杂编辑操作的容错率；
  - 提供草稿保存功能，随时保存当前工作台状态，保障未完成的规划不丢失。
- **精细化路线转移与配送策略**：
  - 在画布中可以直接选中门店或区域，支持精细化的路线转移、配送顺序调整以及特定配送方式的深度定制。

---

### 5. 系统管理与安全密钥配置
- **高德开发者密钥管理 (`/settings`)**：
  - 维护高德地图 Web 端 (JS API) Key 与配套安全密钥（Security Secret / jscode）；
  - 前端输入框**默认开启密码遮罩保护**，防止密钥泄露；
  - **后端 SQLite 持久化与 MD5 加密**：密钥数据存储于后端 SQLite 数据库（`system_settings` 表），并生成 MD5 密文摘要校验；
  - **⚡ API 连通性测试**：支持一键发起高德 API 联通性测试，实时反馈响应延时（ms）与解析验证结果。

## 🛠️ 技术栈

- **前端架构**：Vue 3 + Vite + Element Plus + Vue Router
- **地图引擎**：高德地图 JS API 2.0 (`@amap/amap-jsapi-loader`，加载 Scale, ToolBar, Geocoder, AutoComplete, TruckDriving, Driving)
- **文件解析与导出**：SheetJS (`xlsx`)，纯前端高效解析与生成 `.xlsx` / `.csv`
- **后端架构**：Python 3.10+ / FastAPI / SQLAlchemy / Pydantic
- **求解算法引擎**：Google OR-Tools (CVRP 引导式局部搜索 Guided Local Search)
- **数据库**：SQLite 3（轻量级本地数据库，自动建表与持久化）

## 🚀 快速开始

### 1. 启动后端 (FastAPI)

```bash
cd backend
# 创建并激活 Python 虚拟环境
python3 -m venv .venv
source .venv/bin/activate

# 安装依赖
pip install -r requirements.txt

# 启动后端服务 (默认监听 8000 端口)
uvicorn main:app --reload --port 8000
```
- API 交互文档：`http://127.0.0.1:8000/docs`
- 健康检查：`http://127.0.0.1:8000/health`

### 2. 启动前端 (Vite)

```bash
cd frontend
# 安装前端依赖
npm install

# 启动开发服务器
npm run dev
```
- 本地访问地址：`http://localhost:5173/`

## 📥 Excel / CSV 导入与字段规范

在「门店维护」或规划页面导入门店数据时，系统支持全自动智能表头识别：

| 字段名称 | 推荐表头 | 是否必填 | 说明 |
| :--- | :--- | :---: | :--- |
| **门店编号** | `shop_code` / `门店编号` / `编码` | 是 | 门店唯一编码主键 |
| **门店名称** | `name` / `门店名称` / `shop_name` | 是 | 门店简称或营业名称 |
| **经度** | `lng` / `longitude` / `经度` | 是 | GCJ-02 高德坐标或 WGS84 经度 |
| **纬度** | `lat` / `latitude` / `纬度` | 是 | GCJ-02 高德坐标或 WGS84 纬度 |
| **所属仓库** | `dc_code` / `所属仓库` / `仓库编码` | 选填 | 关联的中心仓编码（如 `9050`） |
| **所属店群** | `cluster_id` / `所属店群` / `店群` | 选填 | 聚类分组编号（整数，如 `1`） |
| **日均箱数** | `avg_loads` / `日均箱数` / `需求量` | 选填 | 配送需求量（箱，缺省 10） |
| **配送频次** | `frequency` / `周配送频次` / `频次` | 选填 | 每周配送次数（1~7次/周） |
| **是否本埠** | `is_homepot` / `是否本埠` / `本埠` | 选填 | `1`/`本埠` 为本埠店，`0`/`外埠` 为外埠店 |
| **指定车型** | `available_truck` / `指定车型` / `车型` | 选填 | 如 `4.2米厢车`，空表示不限车型 |
| **卸货耗时** | `service_time` / `卸货耗时_小时` | 选填 | 单次到店服务耗时（小时，如 0.5 即 30 分钟） |
| **详细地址** | `address` / `详细地址` / `门牌地址` | 选填 | 门店实际街道道路地址 |

## 🔒 高德密钥与环境配置

1. 打开 [高德开放平台控制台](https://lbs.amap.com/dev/key/app)，创建应用；
2. 添加 Key，**服务平台务必选择「Web端 (JS API)」**，获取 `Key` 与配套的 `安全密钥 (jscode)`；
3. 进入本系统前端 **「系统管理 -> 系统设置」** 页面填入 Key 与安全密钥，点击「测试 API 连通性」验证通过后保存；
4. 配置将自动持久化至 SQLite 数据库并进行 MD5 校验，全系统所有地图可视化与路径测算即时生效。
